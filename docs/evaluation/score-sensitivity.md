# Score sensitivity and ablation analysis

Generated by `npm run sensitivity` (packages/synth/scripts/sensitivity.ts) for score model v0.3.0.
Deterministic: fixed scenarios and a seeded random sample, so it reproduces exactly.

**Method.** Every comparison is against the baseline model on the named synthetic scenarios. Rank agreement is
Spearman ρ between baseline and variant totals across all scenarios (1 = same ranking). "Orderings broken" lists
which of the 12 pairwise expectations (decided before the formulas; see orderings.test.ts) no longer hold.

## E. Does any component dominate? (500 random networks, seed 42)

Random event logs from the property-test generator (1–8 people, up to 40 contacts and 20 calls, random
states, ratings, pauses; call log connected in about half). For each component: its nominal weight, the
share of the total's variance it accounts for (cov(contributionᶜ, total) / var(total); shares sum to 1), and
the correlation of the component's value with the total where it is defined.
